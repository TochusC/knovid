# KnoVid 知视 · 前端

面向普通创作者的知识视频工具。打开网站先进入动态展示首页，点击「开始创作」进入工作台。输入一个问题、粘贴论文链接或上传 PDF，查看制作进度，按片段检查讲解与资料，修改旁白和画面参数后更新视频。

## 本地运行

需要 Node.js 22.18+。

```sh
cd KnoVid/frontend
npm install
cp .env.example .env.local
npm run dev
```

打开 http://127.0.0.1:5173。制作 API 默认使用 `http://127.0.0.1:8080`，账号 API 使用 `http://127.0.0.1:3001`。没有后端时可以查看创作界面和本地样片；页面会如实显示连接状态，不会生成模拟作品。

`.env.local` 可配置：

| 变量                   | 用途                                                                          |
| ---------------------- | ----------------------------------------------------------------------------- |
| `VITE_API_BASE_URL`    | 浏览器请求的代理前缀，默认 `/api`                                             |
| `API_PROXY_TARGET`     | Vite 开发服务器连接的制作 API 地址                                            |
| `ACCOUNT_PROXY_TARGET` | 独立账号 API 地址，默认 `http://127.0.0.1:3001`                               |
| `API_PROXY_TOKEN`      | 制作 API 开启 `API_TOKEN` 时使用，仅在开发代理服务器转发，不进入浏览器 bundle |

Vite 将 `/api/v1/*`、`/api/healthz` 转发为后端 `/v1/*`、`/healthz`，账号接口保留 `/api/*`。生产环境应在网关配置相同路径映射并转发 Cookie。后端验证账号会话、项目归属与访客额度；共享代理密钥仅用于服务访问，不能代替用户身份。制作服务通过 `ACCOUNT_API_ORIGIN`（默认 `http://127.0.0.1:3001`）验证登录状态。

## 界面与交互

- React、TypeScript、Vite、Tailwind CSS，shadcn/ui 的 Button、Dialog、Select 组件。
- 蓝紫白配色，提供浅色、夜间和跟随系统三种外观设置，自动记住偏好；页面、弹窗、编辑器和动态插画同步切换。
- 适配桌面和手机，提供键盘焦点、弹窗焦点管理和减少动画支持。
- Motion 入场/展开动画、JavaScript / WebGL 实时绘制的三斜线标志与由品牌元素延展的立体图形。
- 独立首页 `/`：无页眉页脚的全屏知识空间，滚动驱动镜头放大、穿入和场景淡入；支持反向回退、场景跳转、样片播放与动效暂停。工作台入口为 `#/workspace`。
- 首页采用影像海报构图：完整字标与蓝紫色立体三斜线标志分区呈现，浅色为淡蓝白底，夜间为深墨蓝底；标志保持原有长短比例与倾斜方向，通过程序化几何、倒角和光照呈现厚度，轻微悬浮并响应鼠标，随滚动放大；暂停、离场和系统减少动态效果时停止持续动画。首屏标志不依赖图片或贴图素材。
- 后两幕介绍平台的创作流程与设计特点：从想法和资料，到脚本与画面，再到有声成片；三条斜杠品牌元素延展为立体视觉，支持点击查看各制作阶段。平台介绍说明画面可控、局部修改与分工协作，示意画面不代表实际制作状态。
- 无需登录即可试用：每条最多 30 秒，共 3 次生成。新建与保存修改各用一次，失败重试不再扣生成次数，每个作品最多重试两次。
- 试用次数由服务端按访客 Cookie 记录；用完后仍能查看和下载自己的作品。登录后自动认领当前访客作品。
- 主题与论文链接自动保留本地草稿，支持 PDF 拖放与大小检查。
- 作品列表、制作阶段、片段视频预览、资料出处、旁白与画面参数编辑。
- 按版本保存和下载；遇到版本冲突保留未提交内容。
- 账号注册/登录、真实 Credit 余额和流水，连接独立账号接口。会员 Credit 扣费与访客试用额度分别处理，制作计费整合由服务端负责。

## 构建与联调

```sh
npm run build
npm test
npm run preview
```

`npm run build` 包含 TypeScript 检查。构建输出位于 `dist/`。接口约定、当前能力及协作说明见 [INTEGRATION.md](./INTEGRATION.md)。

页面示例使用 `public/examples/orbit.mp4`，它是已有程序化动画样片，不代表新建作品的生成结果。接口测试使用隔离临时目录，不调用模型或写入实际作品数据。
